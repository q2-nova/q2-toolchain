# QEMU prerelease assets

Push a reviewed `qemu-vMAJOR.MINOR.PATCH-rc.N` tag to build a release candidate. A manual **Build the Q2 QEMU asset** dispatch on the default branch runs the same build and smoke checks for validation. The job builds the user and system emulators from the locked public QEMU fork in [the recipe](../q2/toolchain/qemu-ci.json). It unpacks a fresh copy of the archive before checking the two executables. The system check enumerates the Q2 machine and the user check executes a generated static MIPS program. Boot and listening acceptance use the selected consumer image and its own fixtures.

Download `qemu-linux-x86_64.tar.gz` and `qemu-linux-x86_64.tar.gz.sha256` from the selected GitHub prerelease tag. The tag-triggered workflow publishes the prerelease after the checks pass. Select the exact tag in the consumer component configuration. Verify the archive digest before extraction and both binary hashes in `qemu-artifact.json` before use. The archive includes `bin/qemu-mipsel`, `bin/qemu-system-mipsel`, `share/qemu/` and the fork's license text. The Q2 machine takes its boot inputs from the consumer image. The recipe disables installation of QEMU's unrelated firmware blobs.

The runtime ABI is Ubuntu 24.04 x86-64. The receipt lists the resolved runtime library packages per binary and their installed versions. Install those packages on the consumer runner before invoking the binaries. Keep `share/qemu/` beside the `bin/` directory to make the QEMU data directory relocatable.
